# Contributing to Gesture-to-Speech 🤝

First off, thank you for considering contributing! Projects like this get better when more people look at the code.

### How Can I Help?
- **Reporting Bugs:** If something isn't working, please open an issue and describe what happened.
- **Suggesting Features:** Have an idea for a new gesture or a better way to handle the camera? Let me know!
- **Code Changes:** If you want to fix a bug or add a feature:
  1. Fork the repo.
  2. Create a new branch (`git checkout -b feat/amazing-feature`).
  3. Commit your changes.
  4. Open a Pull Request.

I'll be updating this section with specific setup instructions once the core code is in place. For now, feel free to reach out if you have questions!
